# 🌿 The Herbalist's Codex

> *A digital field journal documenting plants, their history, uses, folklore, and the stories found along the road.*

**The Herbalist's Codex** is a front-end web development project designed as an interactive botanical codex belonging to a traveling herbalist and apothecary.

The project combines **web development, botanical knowledge, historical research, and visual storytelling** to create something that feels less like a traditional website and more like a living field journal.

The project is being developed incrementally as I learn new front-end technologies and programming concepts.

---

## 📖 Project Concept

The Codex presents different plants as individual chapters in an apothecary's journal.

Each entry can contain:

- Common and scientific names
- Botanical information
- Historical and traditional uses
- Modern observations
- Folklore and mythology
- Warnings and relevant observations
- Botanical illustrations
- Real photographs for visual reference
- Personal notes from the fictional traveling apothecary

The visual identity is inspired by **old botanical books, apothecary journals, watercolor illustrations, parchment, wood, and natural autumn colors**.

---

## 🚧 Current Status

### Phase 1 — HTML & CSS Foundation ✅

The first version of the Codex has been completed using **HTML5 and CSS3**.

Current features include:

- Semantic HTML structure
- Six documented plant chapters
- Internal navigation between chapters
- Floating navigation menu
- Responsive-friendly document structure
- Watercolor botanical illustrations
- Real botanical photographs
- Custom typography
- Initial visual identity and color palette
- Styled chapter headers and plant sections
- Structured apothecary field notes

The website is currently **static**. JavaScript and dynamic data management will be introduced in later stages.

In Later stages, a EN translation will also be disponibilized.
